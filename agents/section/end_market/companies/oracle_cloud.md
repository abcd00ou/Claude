## Company Overview

Oracle Cloud Infrastructure (OCI) is a major hyperscaler distinguished by its large-scale bare-metal GPU supercluster offerings for AI training and inference. OCI is one of four partners in the $500B U.S. Stargate AI infrastructure initiative and is the lead infrastructure provider for Stargate UAE (1 GW, Abu Dhabi). Oracle was confirmed as the first major cloud provider to deploy Ultra Ethernet-compliant hardware (AMD Pensando Pollara 400GbE NICs + AMD Instinct MI350X). In 2026, OCI is deploying a 50,000-GPU AMD Instinct MI450 AI supercluster.

**Source:** Oracle Cloud Infrastructure, Oracle Newsroom / NVIDIA Press Release, 2025–2026

## Supply Chain Position

OCI is a buyer (end market) of AI GPUs (NVIDIA GB300, AMD MI450), advanced networking (NVIDIA InfiniBand, AMD Pensando Ultra Ethernet NICs), and datacenter infrastructure (cooling, power, transformers). OCI is notable as the first hyperscaler to deploy Ultra Ethernet hardware in production — using AMD Pensando Pensando NICs rather than NVIDIA InfiniBand for its AMD MI350X and MI450 clusters.

**Key customers (publicly stated):** OpenAI (Stargate U.S./UAE), U.S. government, enterprise AI customers, sovereign AI nations  
**Key suppliers (publicly stated):** NVIDIA (GPU superclusters), AMD (MI350X, MI450, Pensando NICs), Cisco

**Source:** Oracle and AMD Expand Partnership, Oracle Newsroom, 2025-10-14; Oracle / NVIDIA Press Release, 2025

## Updates

### Update: 2025-10-14 — Oracle first major cloud to deploy Ultra Ethernet-compliant hardware; AMD Pensando 400GbE + MI350X; 50,000-GPU MI450 announced for Q3 2026

> Oracle Cloud Infrastructure is explicitly confirmed as the first major cloud provider to deploy Ultra Ethernet-compliant hardware: AMD Pensando Pollara 400GbE NICs paired with AMD Instinct MI350X GPUs. Broad availability at OCI was targeted for H2 2025. Oracle is additionally confirmed to deploy a 50,000-GPU AI supercluster using AMD Instinct MI450 starting Q3 2026, each GPU configurable with AMD Pensando "Vulcano" 800G NICs supporting Ultra Ethernet. AMD Pensando Vulcano 800G NIC (PCIe Gen6, supporting UE and UALink) targets 2026.

**Source:** Oracle and AMD Expand Partnership to Help Customers Achieve Next-Generation AI Scale, Oracle Newsroom, 2025-10-14, https://www.oracle.com/news/announcement/ai-world-oracle-and-amd-expand-partnership-to-help-customers-achieve-next-generation-ai-scale-2025-10-14/
