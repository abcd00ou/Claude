# Proof Sheet - AI Server DDR5 / MRDIMM Attach

**Audience:** OEMs, ODMs, enterprise AI server teams  
**Goal:** Win server BOM attach and higher-density memory mix.

## Required Proof

- Platform QVL status.
- DIMM density options.
- Power per DIMM.
- Reliability qualification.
- Thermal limits by server class.
- MRDIMM compatibility, where applicable.
- Supply availability by quarter.
- Comparison against incumbent BOM.

## Customer Ask

Request a BOM review before platform lock and propose higher-density attach options.
