# Amazon / AWS AI Memory Revenue Brief

**Commercial posture:** Expand  
**Decision window:** 0-90 days  
**Primary products:** HBM3e/HBM4, DDR5, enterprise SSD, QLC/KV SSD  
**Recommended ask:** Trainium3 memory attach and AI storage TCO session.

## Account Signal

AWS Trainium3 UltraServers are generally available. AWS states each Trainium3 chip includes 144 GB HBM3e and 4.9 TB/s memory bandwidth, and each Trn3 UltraServer scales to 144 chips.

## Product Fit

- HBM: custom ASICs create direct HBM load, not only merchant GPU demand.
- DDR5: supporting host and storage infrastructure for AI clusters.
- Enterprise SSD/QLC: checkpoint, model loading, dataset, and retrieval economics.
- KV SSD: future agentic AI retrieval pattern discussion.

## Pain Message

Trainium improves token economics only if memory and storage subsystems keep pace with dense, expert-parallel, and agentic workloads.

## Recommended Sales Motion

Propose a Trainium memory attach map:

1. HBM load by Trainium cluster scale.
2. Host DDR5/MRDIMM attach.
3. Enterprise SSD capacity per training/inference pod.
4. QLC and KV SSD role in retrieval and checkpointing.

## Proof To Bring

- HBM roadmap and allocation view.
- AI SSD TCO calculator.
- Endurance and power/TB proof for enterprise SSD.
- Platform qualification plan.
