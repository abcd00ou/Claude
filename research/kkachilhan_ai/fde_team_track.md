## 1. 무엇을 바꾸나

| | 기존 FDE 양성 과정 | 팀 과제 랩 (이번 설계) |
|---|---|---|
| 대상 | 고객사에 들어가는 외부 FDE | **현업 직원** (영업, 마케팅, 상품기획) |
| 관점 | FDE가 고객 조직을 바꾼다 | **내가 내 팀 업무를 AI로 바꾼다** (꼭짓점 AX, 03-17 / 리서처 모드, 11-02) |
| 기간 | 12주 | 팀별 미션 4개 (미션당 30~60분) + 공통 캡스톤 1개 |
| 도구 | 범용 에이전트 일반 | **Codex** (빠른 시작에서 설치한 환경 그대로) |
| 결과 확인 | 강사 평가 | 웹에서 **숫자 정답 자동 확인** + 자기 점검 체크리스트 + 모범 답안 |

FDE 과정의 원칙 중 현업에게도 그대로 필요한 다섯 가지를 모든 미션에 넣습니다.

1. **요청을 그대로 때려박지 않는다.** 먼저 계획과 접근 방식을 받는다 (11-02)
2. **원본은 건드리지 않는다.** 되돌릴 수 없는 행동(발송, 덮어쓰기)은 사람이 승인한다 (02-27)
3. **팀의 암묵지를 규칙으로 적는다.** 엑셀 매크로와 시니어의 머릿속에 있는 기준을 Codex에 알려 준다 (03-05, 04-09)
4. **숫자는 검증한다.** 결과의 행 수, 합계, 기준 위반 건수를 직접 확인한다
5. **데이터 등급을 지킨다.** 원가, 단가 같은 대외비는 외부로 보내지 않는다 (케이스의 정해린 책임)

## 3. 공통 미션 0: 우리 팀 업무 지도 (20분)

- **상황:** 본부장이 "AI로 뭘 할 수 있는지 각 팀이 1장으로 가져오라"고 했습니다.
- **할 일:** 반복 업무 5개를 적고, 주기, 걸리는 시간, 사용하는 데이터, 실수했을 때 되돌릴 수 있는지를 표로 만듭니다. Codex에게 "맡길 것 / 사람이 승인할 것 / 맡기지 않을 것"으로 나누게 하고, 그 이유를 받습니다.
- **산출물:** `업무지도.md`
- **자기 점검:** 고객에게 나가는 일(발송, 견적 확정)을 '맡길 것'에 넣지 않았는가?

## 4. 팀별 미션

각 미션은 같은 틀로 구성합니다: **상황(인물 대사) → 자료 → 목표 → 프롬프트 뼈대(목표·입력·출력·제약·검증 빈칸) → 단계별 힌트 → 정답 확인 → 모범 답안 → 회고 질문**

### A. B2B 영업팀

| # | 미션 | 쓰는 자료 | 배우는 원칙 | 정답 확인 |
|---|---|---|---|---|
| S1 | **거래처별 재고 확인.** 재고 개월 수 = (현재고+입고예정) ÷ 월평균 출고. 1개월 미만 부족, 3개월 초과 과다, 출고 0은 무출고 | dealer_stock (신규) | 팀 기준을 규칙으로 | 부족 3 · 과다 3 · 거래처 5곳 (청호FA = 청호에프에이) |
| S2 | **특판가 요청 검토.** 9건을 현행 기준(15% 이하 영업 승인, 마진 25% 미만은 상품기획 검토, 15~20%는 로봇 OEM+LOI만 전무 승인)으로 판정 | special_price_requests (신규), price_list | 영업 12% vs 상품기획 15% 기준 충돌 | 불가 3 · 승인 가능 4 |
| S3 | **고객별 집계.** VOC 고객 표기 19가지를 8곳으로 통일하고 고객별 VOC 접수·CRM 메모 건수 집계 | voc_raw, crm_notes | 고유 회사 단위 (11-02) | 고객 8곳 · 아크봇 VOC 11건 |
| S4 | **거래선 특징 정리 스킬.** 고객 이름을 넣으면 CRM·VOC·리드·특판가에서 1쪽 프로필(출처 표시)을 만드는 재사용 지시문 | crm, voc, leads, 특판가 | 반복 업무는 스킬 하나로 (07-06) | 자기 점검 |

### B. 마케팅팀

| # | 미션 | 쓰는 자료 | 배우는 원칙 | 정답 확인 |

## 5. 공통 캡스톤: DX-7 Go/No-go (60분)

- **상황:** 강도윤 전무가 "다음 분기 회의에서 DX-7 개발을 시작할지 결정하겠다"고 합니다.
- **할 일:** 자기 팀 산출물(A1 고객 단위 수요, B2 경쟁 비교, C3 리서치 브리프 등)을 모아 1쪽 결정 메모를 씁니다. 다른 팀 미션을 하지 않았다면 모범 답안을 가져다 씁니다.
- **메모 형식:** 권고(Go / No-go / 조건부) → 근거 3개(출처 포함) → 리스크 → 결정 전에 확인할 질문
- **자기 점검:** 숫자마다 어느 파일의 몇 행에서 나왔는지 따라갈 수 있는가?

## 6. 웹 기능 (ai-work-lab에 추가)

| 기능 | 내용 |
|---|---|
| 팀 선택 | 빠른 시작 마지막 단계와 대시보드에서 진입. 인물 카드 3장 |
| 미션 화면 | 상황 → 자료 → 목표 → 프롬프트 뼈대 → 힌트(단계별로 열기) → 정답 확인 → 모범 답안 → 회고 |
| 자료 받기 | ① **"파일 만들기" 프롬프트 복사**: CSV 내용을 담은 지시문을 Codex에 붙여넣으면 연습 폴더에 파일이 생깁니다 ② 사내 서버나 Vercel에 배포했을 때는 ZIP 다운로드도 제공 (Claude 페이지에서는 다운로드가 막혀 있어 ①만 동작) |
| 정답 확인 | 숫자를 입력하면 맞음 / 다시 확인으로 답합니다. 틀리면 흔한 실수 힌트를 보여 줍니다 (예: 56 → 중복 제거 안 함, 51 → 고객명 통일 안 함) |
| 모범 답안 | 정답 확인을 한 번 하거나 "포기하고 보기"를 눌러야 열립니다 |
| 진행률 | 팀별, 미션별 완료 상태를 브라우저에 저장 |

## 7. 결정 사항 (2026-11-23)

1. 영업 미션: 재고 확인, 특판가 검토, 고객별 집계, 거래선 특징 정리 스킬
2. 마케팅 미션: 경쟁 비교표, 시장 동향 조사, 수익선 개선 방향 (+ 전시회 리드 우선순위 유지)
3. 상품기획 미션: 설계안 그대로
4. 업종: 대성모션(제조 B2B) 유지
5. 형식: 자습형 (서버 없이 정답 확인과 모범 답안까지)
