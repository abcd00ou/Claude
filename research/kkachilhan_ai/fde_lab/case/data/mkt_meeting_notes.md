# 마케팅팀 주간회의 메모 (2026-06-29, 작성: 배수빈)

> 가상 자료입니다. 참석: 문서진 팀장(상품기획), 배수빈 과장, 법무팀 담당자(30분 참석)

1. **전시회 성과 보고**
   - 배수빈: 스마트팩토리엑스포 리드 16건으로 보고하고 싶음. 방문도 관심 고객이니 리드로 세야 전시회 성과가 보임
   - 문서진: 영업에 넘기는 리드는 샘플·견적 요청만. 방문만 한 건 영업이 전화해도 소용없음
   - → 결론 못 냄. 보고서에 두 숫자를 다 쓸지 다음 주에 다시 논의

2. **고객용 제안서의 경쟁 비교**
   - 문서진: 전무님 보고에는 경쟁사 이름 실명으로 (돌려 쓰지 말 것)
   - 법무: 고객에게 나가는 자료에서 경쟁사 실명을 넣어 깎아내리는 비교는 금지. "A사"로 쓰거나 공개 스펙 비교만
   - → 내부 보고와 외부 자료 기준이 다름. 둘 다 맞음

3. **시장 자료 인용**
   - 작년 브로셔의 "협동로봇 시장 연 30% 성장" 문구: 출처를 아무도 모름. 누가 넣었는지도 모름
   - 문서진: 출처와 발행연도 없는 숫자는 앞으로 쓰지 않기로
   - 작년 브로셔 "DX5-750 토크 업계 최고" 문구도 카탈로그 기준이었음. 연속 토크로 보면 Kestrel KM-J80(2.60)이 더 높음

4. **경쟁사 소문 공유**
   - 배수빈: Kestrel 가격 인하 소문 같은 건 빨리 영업에 돌려야 대응함
   - 한경수(메신저로 의견): 확인 안 된 정보 돌리면 영업이 그걸로 가격 깎아 달라고 옴. 확인 전엔 돌리지 말 것
   - → 팀장 선에서 정리 안 됨. 문 팀장이 전무님께 여쭤보기로

5. **Zhenli 대응**: 가격으로 대응하지 않는다. 대리점용 TCO 비교 자료(수명, 튜닝 시간, AS) 업데이트
6. **6월 실적 인용**: 마감(7/7) 전 숫자는 "잠정"으로 표기
