## A. 실습 자료

### 상황
여러분은 1인 FDE입니다. 대성모션 상품기획팀이 보낸 RFP(`case/01_company.md` 4절)를 받았습니다. 고객사 미팅은 4주차부터 시작합니다. 그 전에 공개 자료만 가지고 준비합니다.

### 입력 자료
- `case/01_company.md`, `case/02_people.md`
- `case/data/sales_sap_extract.csv`, `price_list.csv`, `competitor_specs.csv`
  - 실제 프로젝트였다면 미팅 전에는 받지 못하는 자료입니다. 교육 편의상 공개 실적 수준의 자료로 간주합니다.

### 과제
1. **사전 브리프 (1~2쪽):** 고객사에 들어가기 전에 알고 있어야 할 것을 정리합니다.
   - 사업 구조
   - 실적 추세
   - 경쟁 상황
   - 이해관계자 가설
   - 미팅에서 확인할 질문 10개
2. **RFP 다시 읽기:** RFP에서 "SI 문법"에 해당하는 부분을 표시하고, 그 이유를 적습니다.
3. **FDE 제안서 v0 (1쪽):** 같은 요청을 FDE 방식으로 다시 씁니다.
   - 필수 항목: 기간, 투입 형태, 첫 4주 활동, 종료 조건, 산출물

## B. 예상 산출물

### 1-1. 사전 브리프 v1 (모범 답안)

**1) 사업 구조**
- 모션사업본부의 연매출은 약 650억 원으로 회사의 약 31%입니다.
- 제품군은 DS-3(범용), DX-5(고정밀, 로봇), HR(감속기) 세 가지입니다.
- 일체형 DX-7은 컨셉 단계에 있습니다.

**2) 실적 추세** (SAP 추출 데이터, 2025년 7월~2026년 6월)

| 관찰 | 근거 수치 |
|---|---|
| 2026년 상반기 매출 320.8억 원 | DS-3 144.7억, DX-5 125.9억, HR 50.3억 |
| **DX-5가 성장을 이끎** | DX5-750 분기 매출 17.0억 → 21.8억 → 26.9억 → 34.6억 (26Q2 전분기 대비 +28.8%) |
| **DX-5는 로봇 OEM에 의존** | DX-5 상반기 매출의 53.6%(67.5억)가 로봇 OEM |
| **DS3-100은 하락하고 저마진** | 분기 매출 8.0억 → 6.6억 → 5.5억 → 4.7억. 마진율 20.3% → 18.6% |

**3) 경쟁 상황** (`competitor_specs.csv`)
- 미라텍이 일체형 중공축 제품 MR-H70J를 공개했습니다. 해외 Kestrel KM-J80도 일체형입니다.
- **우리에게는 일체형 제품이 없습니다.**
- 저가 시장에서는 Zhenli ZL-100이 245천 원으로, 우리 DS3-100(380천 원)보다 35.5% 쌉니다.
- 출처 신뢰도가 제각각입니다. 데이터시트, 카탈로그, 구두 확인이 섞여 있습니다.

**4) 이해관계자 가설** (4주차에 검증)

| 인물 | 가설 |
|---|---|
| 강 전무 | 진짜 관심사는 리포트 자동화보다 "신제품(일체형) 결정"일 것이다 |
| 문 팀장 | RFP 5종은 희망 목록이다. 실제 고통은 반복 집계 업무일 것이다 |
| 한 부장 | 가격·포트폴리오 판단 노하우의 보유자일 것이다 |
| 오 사원 | VOC 취합 실무자이며 메인테이너 후보일 수 있다 |
| 정 책임 | 프로젝트 성패를 가를 거버넌스 게이트키퍼다 |
| (미확인) | VOC 원천을 가진 영업 쪽 키맨이 따로 있을 것이다 |

**5) 첫 미팅 확인 질문 10개**
1. 이 프로젝트가 성공하면 본부장님은 누구에게 무엇을 보고하시나요?
2. 에이전트 5개 중 하나만 된다면 무엇이 남아야 하나요?
3. VOC 원본은 누가, 어디에, 어떤 형식으로 모으나요?
4. 분기 포트폴리오 리뷰 준비 2주 중 가장 오래 걸리는 단계는 무엇인가요?
5. 일체형(DX-7) 출시는 지금 누가, 언제, 어떤 기준으로 결정하나요?
6. 가격과 특판가 판단은 누가 하고, 그 기준은 어디에 적혀 있나요?
7. 외부로 나가면 안 되는 데이터는 무엇이고, 사내에 승인된 AI 도구가 있나요?
8. 지난번 신제품(B2)의 결정 과정에서 무엇이 아쉬웠나요?
9. 프로젝트가 끝난 뒤 이 일을 계속 돌볼 사람은 누구인가요?
10. 영업과 상품기획이 숫자를 맞출 때 자주 생기는 문제는 무엇인가요?

### 1-2. RFP 분석 (모범 답안)

| RFP 항목 | SI 문법인가 | 이유 (근거 영상) |
|---|---|---|
| 에이전트 5종 구축 | 예 | 업무 단위로 에이전트를 짓는 것은 SI 방식의 반복입니다. 5종이 50종이 되면 유지보수 지옥이 됩니다 (07-06) |
| 구축 6개월 + 유지보수 12개월 별도 | 예 | 구축과 유지보수를 나누면, AI가 빠르게 바뀌는 속도를 따라가지 못합니다. 외부가 유지보수하면 결국 녹이 습니다 (03-11, 08-12) |
| 산출물이 "소스 + 매뉴얼 + 교육 1회" | 예 | 내재화가 아니라 납품입니다. 교육 1회로는 메인테이너가 생기지 않습니다 (09-30) |
| 대시보드 제공 | 부분적으로 | 보고 레이어 요구는 타당합니다. 다만 누가 어떤 결정을 위해 보는지가 빠져 있습니다 (06-11) |
| 기술 60 / 가격 40 평가 | 참고 | 문제 정의 역량을 평가하는 항목이 없습니다 |
| 보안 규정 준수 | 아님, 타당 | 데이터 등급별 접근 채널을 설계해야 합니다 (03-11) |

### 1-3. FDE 제안서 v0 (모범 답안)

**제목:** 상품기획 의사결정 가속 프로젝트 (12주, 1인 FDE)

| 항목 | 내용 |
|---|---|
| 목표 | "에이전트 5종"이 아니라, 상품기획팀이 **사내 승인 범용 에이전트 하나로 반복 업무와 보고를 처리하는 상태**를 만듭니다 |
| 투입 | FDE 1명이 주 4일 상주합니다. 고객 측 카운터파트 1명(메인테이너 후보) 지정을 요청합니다 |
| 첫 4주 | ① 이해관계자 인터뷰와 토폴로지 스캔 ② 데이터 등급 분류와 접근 채널 합의 ③ 문제 정의서와 우선순위 1건 합의 |
| 5~12주 | 우선순위 업무 1건을 실무부터 본부장 보고까지 버티컬로 구현하고, 메인테이너를 양성합니다 |
| 종료 조건 | 고객사 메인테이너가 FDE 없이 규칙 변경 1건을 처리하고, 월간 보고 1회를 직접 생성합니다 |
| 산출물 | 토폴로지 맵, 문제 정의서, 에이전트 세팅(지침·스킬·데이터 연결), 컨텍스트 그래프, 평가 리포트, 인수 패키지 |
| 하지 않는 것 | 업무별 개별 에이전트 개발, 12개월 외부 유지보수 계약 |
