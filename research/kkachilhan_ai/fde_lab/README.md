# FDE 실습 랩: 대성모션 상품기획팀 (12주)

- **작성일:** 2026-11-02
- **상위 문서:** [../fde_curriculum.md](../fde_curriculum.md) (12주 과정 설계), [../insights.md](../insights.md) (영상 분석)
- **목표:** 수강생이 12주 뒤 **1인 FDE로 실제 조직의 AX에 투입될 수 있는 상태**가 되는 것
- **성격:** 회사, 인물, 데이터는 모두 교육용 **가상 자료**입니다. 방법론의 근거는 '까칠한 AI' 영상이고, 각 주차 문서에 영상 날짜를 표기했습니다. 실습 설계와 모범 답안은 정리자가 만들었습니다.

## 1. 한 팀, 한 줄기 이야기

제조업 B2B 회사(서보모터·감속기) **대성모션 모션사업본부 상품기획팀**의 AX 프로젝트 하나를 12주 동안 끝까지 수행합니다. 영업, 마케팅, 상품기획이 맞물린 팀입니다.

```
 W1 사전 브리프 ─ W2 스킬 3개(가정 기반) ─ W3 범용 에이전트 설계
        │                  │                      │
        └──────── W4 토폴로지 스캔 (숨은 키맨 윤태호, 메인테이너 후보) ─┘
                           │
                 W5 문제 정의: "에이전트 5종" → 진짜 문제 "DX-7 판단 근거"
                           │
                 W6 암묵지 K1~K12 → W2의 가정을 교정 (51건 → 37건)
                           │
                 W7 버티컬: VOC → 월간 리포트 → 분기 결정 메모
                           │
                 W8 내재화 설계 + 1인 FDE 부담 관리
                           │
     [캡스톤, 혼자 수행] W9 실전 이전 → W10 숫자 충돌 → W11 DX-7 Go/No-go → W12 인수·퇴장
```

**빌드업 장치 (앞 주차의 결과가 뒤에서 검증되는 지점)**

| 앞 주차 | 뒤 주차 | 무엇이 이어지나 |
|---|---|---|
| W2 가정 "카탈로그 토크로 비교" | W6 K7 교정 | 경쟁 비교의 결론이 뒤집힘 |
| W2 가정 "같은 날 중복만 제거" | W6 K8 교정 | VOC 51건 → 37건 |
| W3 데이터 등급표를 스킬에 강제하지 않음 | W7 보안 사고 | 거버넌스의 중요성 |
| W4 메인테이너 후보 2명 | W12 한 부장 휴직 | 백업 구조의 가치 |
| W5 가격 시뮬레이션 보류 약속 | W11 가격 포지셔닝 | 약속 이행 |
| W6 K9 확인 질문 | W7 우선순위 | 가중치가 1위를 결정 |
| W8 판단 사례 "상황 + 판단 + 이유" | W12 검토자 공백 | 체계가 멈추지 않음 |
| W9 "케이로보" 별칭 누락 | W12 인수 확인 PR | 메인테이너 단독 처리 |

## 2. 1인 FDE로 운영하는 이유와 보완 장치

- 화자는 FDE가 2~3인 팟으로 일하고 솔로 프로젝트는 피해야 한다고 말했습니다 (08-12, 07-14). 이 랩은 사용자 요구에 따라 **1인 FDE**를 목표로 합니다.
- 그래서 팟의 역할을 다음과 같이 대체합니다.

| 팟 역할 | 1인 FDE에서의 대체 |
|---|---|
| 서포터 | AI 에이전트. 동시 세션은 3개 이하로 제한합니다 |
| 작업반장 | FDE 본인 + 고객 측 카운터파트(오지민)와 매일 15분 동기화 |
| 부담 공유 | 외부 멘토 주 1회 리뷰, 매주 금요일 스폰서에게 1쪽 공유 (W8) |

- 1~8주차는 수강생끼리 동료 리뷰를 합니다. 9~12주차 캡스톤은 완전히 혼자 수행합니다.

## 4. 운영 가이드 (강사용)
- 매주 시작할 때 해당 주차 문서의 **A 파트만** 배포합니다. B 파트(예상 산출물)는 제출 후 피드백할 때 공개합니다.
- `case/data/prompt_log_moon.md`와 `interview_han.md`는 6주차에 배포합니다.
- 롤플레이 전에 `instructor/case_secrets.md` 3절(인물별 숨은 정보)을 숙지합니다. 수강생이 맞는 질문을 했을 때만 정보를 공개합니다.
- 숫자 정답은 `case_secrets.md` 5절과 `voc_answer_key.csv`가 기준입니다. 판매 데이터는 고정 시드로 생성했으므로 다시 생성해도 같은 값이 나옵니다.
